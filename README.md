# WOVO LOVE — Landing Page Prototype

A public-facing **landing-page prototype** for WOVO LOVE, a relationship product built around intentional connection, privacy, and thoughtful interaction.

> **Scope:** This repository contains the standalone landing-page implementation. It is **not** the full WOVO LOVE mobile application, backend, or production release.

## Product direction

The landing page explores a calm, editorial presentation for a relationship platform designed around meaningful introductions rather than an endless swipe feed. It uses an intentionally warm visual system, responsive layouts, and lightweight interactive presentation.

## Technology

- HTML, CSS, JavaScript
- Responsive page layouts and typography
- Browser-based visual interaction

## View locally

1. Clone this repository.
2. Open `index.html` in a modern browser.

No application credentials or private backend access are required to inspect the public landing-page source.

## Engineering context

The broader WOVO LOVE work also involved React Native/Expo, TypeScript, backend and privacy architecture, lifecycle rules, accessibility, and testing. **That application source is private and is not included here.** This page should not be treated as evidence that every planned product capability is shipped.
